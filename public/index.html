开始监控

Windows 原生采集 / Mihomo 兼容接口

  1. 选择采集方式

    直连使用 Windows 原生采集，无需代理。在设置中授权采集助手；也可选择 Mihomo 兼容接口。

  2. 连接本地控制接口

    优先自动发现。手动配置时使用 external-controller 地址，不能填代理端口。密钥通过 MIHOMO_SECRET 提供。

  3. 让 Codex 产生新请求

    保持程序运行，等待两次采样。只累计建立基线后的新增流量，其他程序不会计入 Codex。

自动发现失败？查看手动配置

复制程序目录中的 config.example.json 为 config.local.json，按代理实际控制地址填写 controller，然后完整退出并重新启动程序。下面仅为示例。 

{ "controller": "http://127.0.0.1:9090" }

需要授权时，在启动程序的环境中设置 MIHOMO_SECRET。不要把密钥写进截图、反馈或分享内容。

    统计口径

    Windows 原生模式记录 TCP/UDP 进程网络事件（包括回环连接）；Mihomo 模式仅覆盖其控制器中的连接。同一时刻只使用一个来源，不叠加两者。统计不是 VPN 账单或网卡总流量；丢失事件、采样缺口与离线期间不补算。切换来源会标记缺口，历史可能包含不同统计口径。不会按域名或 token 猜测会话用量。

    1–365 天。保存后在下次成功采集时按新期限清理；缩短期限会删除较早数据，延长不会恢复已删除数据。

    自动模式优先使用已授权的原生采集，否则尝试 Mihomo。Windows 授权仅提升采集助手；退出程序后授权结束，开机自启不会自动弹出授权。

    接口地址、采样周期及子进程范围可在 config.local.json 中设置，修改后重启生效。接口密钥通过 MIHOMO_SECRET 环境变量提供。
